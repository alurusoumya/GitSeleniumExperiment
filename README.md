# Git Selenium Experiment

## Objective
To demonstrate Git feature branching and Selenium WebDriver automation.

## Technologies Used
- Java 21
- Maven
- Git and GitHub
- Selenium WebDriver
- Chrome Browser

## Test Description
The Selenium program opens the SauceDemo website, enters valid login credentials, and checks whether login is successful.

## Expected Result
The browser should navigate to the inventory page and display a successful login message.
